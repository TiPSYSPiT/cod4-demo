.dm_1 · Call of Duty 4 / CoD4X

CoD4 Demo Inspector

Drop in a demo and it is decoded in your browser: Huffman stream, gamestate and server commands. You get teams, player stats, a round-by-round breakdown and the chat log. The file never leaves your machine.

Drop a demo here – or
Client demo from main/demos or mods/<mod>/demos, e.g. demo0025.dm_1

The container is a run of 0 snapshot / 1 frame / 2 protocol records; each snapshot payload is Huffman-coded with CoD4's static frequency table and holds byte-aligned svc opcodes. This parser reads the gamestate config strings, svc_configclient (player names) and every svc_serverCommand up to the first snapshot – scoreboards, chat and round status. Delta entities are decoded as well, which is where the obituaries live – that is the kill feed: killer, victim and weapon. Format reference: Iswenzz/CoD4-DM1.
